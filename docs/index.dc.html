The problem

Every student needs a tutor. Few can afford one.

Human tutoring doesn't scale

One-on-one attention is what moves grades — but it's priced for the few, and good tutors are scarce outside big cities.

Generic AI hands out answers

Students paste the problem, copy the solution, and move on. Homework gets done — learning doesn't happen.

The solution

A study buddy, not an answer machine.

01

Follows the student's approach — it never drags them down its own path.

02

Voices doubt, not diagnosis — the student discovers the mistake, so it sticks.

03

Soft intervention after 3 misses — a direct hint at the next step. Never the answer.

"You forgot to check the case x = 0."

What a teacher-bot says

"Hmm, I tried that route too and got stuck right around here… what did you do at this step?"

What D-Friend says

The pedagogy

Done beats Perfect.

Problem → Done → Execute → Optimize

Wrong answers still move the bar. Only real submissions count, correct ones count more — and gaming it pauses progress.

P1 REINFORCE Lock in session-one knowledge
P2 CHALLENGE Harder, same pattern
P3 EXPLORE Non-standard — breaks the old pattern
P4 EXTEND Confidence with the new pattern

Fixed order P1 → P4 — the P3 → P4 pair only works back-to-back.
